# Лёгкие улучшения тренажёра

## Цель

Сделать повторение и поиск вопросов удобнее, не добавляя сервер, зависимости
или сетевое хранение. Все новые данные остаются в браузерном `localStorage`.

## Что уже работает

- Варианты ответа перемешиваются перед показом; буквы `A–D` соответствуют
  видимому порядку.
- Клавиши `1–4`, `A–D`, `Enter` и пробел управляют раундом.
- У каждого из 421 вопросов есть русское пояснение. Оно показывается после
  ответа и в раскрытой карточке базы.

Эти возможности сохраняются без новой реализации.

## Поиск в базе

Поле поиска на экране базы проверяет один нормализованный поисковый текст для
каждой записи. В него входят формулировка вопроса, название темы, китайские
варианты ответа, правильный вариант и русское пояснение.

Поиск остаётся подстрочным, без отдельного индекса или библиотеки. Он работает
в памяти по 421 записи и запускает обычную перерисовку постраничного списка.
Подсказка поля явно перечисляет доступные типы текста.

## Повтор ошибки внутри раунда

При первом неверном ответе текущего раунда запись добавляется в очередь одного
повтора. Она возвращается после трёх следующих показанных вопросов. Если до
конца исходного раунда осталось меньше трёх вопросов, запись показывается перед
итогами.

Один вопрос возвращается не более одного раза в раунде. Неверный ответ на
повторе обновляет общий прогресс и результат раунда, но не добавляет запись в
очередь снова. Повтор получает новую случайную перестановку вариантов.

## Запоминание настроек

Настройки раунда хранятся отдельной записью `localStorage` с версией: выбранные
темы, год, этап, режим, размер раунда и ограничение «только проверенные».

При запуске приложение читает запись, проверяет типы и отбрасывает темы, годы,
этапы и режимы, которых больше нет в банке. Повреждённая запись или недоступный
`localStorage` дают настройки по умолчанию. Прогресс остаётся в существующей
отдельной записи, поэтому форматы экспорта и импорта не меняются.

## Изменяемые части

- `src/quiz.mjs`: поиск по полям записи и очередь повтора как тестируемые чистые
  функции.
- `src/quiz.ui.js`: состояние очереди, показ повторного вопроса и чтение/запись
  настроек.
- `src/template.html`: уточнённая подсказка поиска.
- `test/quiz.test.mjs`: сценарии поиска, очереди и нормализации сохранённых
  настроек.
- `CHANGELOG.md`: краткая запись о пользовательских изменениях.

## Проверка

Нужны модульные проверки поиска, порядка повтора и очистки неверного сохранённого
состояния. После сборки запускаются `node --test test/*.test.mjs` и
`python3 -m unittest discover -s test -t .`; затем проверяется итоговый HTML и
ручной сценарий в браузере.
