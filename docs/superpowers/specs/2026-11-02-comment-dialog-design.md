# Комментарии и возврат после раунда

Макет согласован пользователем 2026-11-02: «Подходит, делай».

- «На главную» в итогах — полноценная второстепенная кнопка рядом с «Новый раунд», на телефоне на всю ширину. Аналогичный возврат в «Чэнъюй» использует тот же стиль без изменения подписи.
- Заголовок редактора — «Комментарий к вопросу»; рядом переход «Все замечания».
- Вопрос и его метаданные остаются видимыми; показанные варианты раскрываются по необходимости. Не показывать пустой блок вариантов во «Вспомни сам».
- Поле комментария крупное, автосохранение остаётся. «Подтвердить» завершает ввод и закрывает окно, сохраняя раунд и комментарий.
- «Подтвердить» находится в нижней панели; на телефоне занимает всю ширину и расположена последней. Панель остаётся доступной при прокрутке содержимого и уменьшении видимой области экрана.
- «Снять отметку» — второстепенное действие в нижней панели. Выгрузка, копирование и обмен находятся в списке «Все замечания». В списке есть нижняя кнопка «Закрыть».
- Сохранить обе темы, существующие шрифты, Escape, фокус, защиту при недоступном хранилище и синхронизацию замечаний между вкладками. `src/ink/` не изменять.

## Подход

Выбран согласованный компактный редактор с отдельной нижней панелью. Простое переименование верхней кнопки не решает проблему доступности на телефоне; сохранение выгрузки внутри редактора конкурирует с подтверждением. Использовать существующий native dialog и общие кнопки сайта.

## Проверка и публикация

Браузерная проверка подтверждения, возврата, автосохранения, длинного контекста, ширины 320px и уменьшенной видимой области; существующие проверки экспорта и конфликтов вкладок. Перед слиянием в основную ветку `master` — независимое ревью. Затем проверить публикацию GitHub Pages.
