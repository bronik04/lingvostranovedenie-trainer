## Global Constraints

- Ориентир 90 строк (63/27); допустимый диапазон 80–100 при подтверждённых фактах.
- В каждой таблице name/country/location/period/feature — zh, description — ru. Country — только фильтр.
- Минимум два официальных/академических источника и пять российских строк на колонку каждой таблицы.
- Китайские собственные имена только из источников; ограничение цитирования 25 слов на публикацию с повторами.
- Вопросы [], остальные досье, банк, сайт, sources/ и книга не меняются; только локальный коммит.
