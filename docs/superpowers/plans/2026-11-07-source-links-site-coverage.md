# Ссылки и покрытие сайта — план исполнения

> Исполнение в текущем чате по команде автора. Навык: superpowers:executing-plans.

**Goal:** Исправить два недоступных источника и пересчитывать карту по доступным вопросам.
**Architecture:** Источники меняются в исходных слоях evidence; карта повторно использует
`scripts/site_bank.py`. Алгоритм поиска тем остаётся прежним.
**Tech Stack:** Python, unittest, существующая сборка HTML и Node-тесты.
**Spec:** `docs/superpowers/specs/2026-11-07-source-links-site-coverage-design.md`.

## Ограничения

- Подсказки, группы фактов, подписи, id, ключи и формулировки не менять.
- Не пересчитывать старый отчёт ссылок как будто проверен весь банк.
- Не использовать отменённую количественную цель.

## Проверяемые риски

- HTTP 200 на HEAD может скрывать отказ на GET: читать содержимое новых источников.
- Исключения сайта: обычная запись, скрытая региональная, разрешённый id,
  принятое и черновое встраивания, явное редакторское скрытие.
- Пустая выборка: нулевые доли и пустые темы без деления на ноль.
- Скрытый вопрос не должен попадать в список вне тем или завышать покрытие.
- Повторы одного факта не выдаются за содержательную полноту темы.
