# Книга для чтения «中国文化故事»

Тексты по-китайски уровня HSK 4+ о мифах, легендах, чэнъюй и культуре Китая для школьников,
которые готовятся к олимпиаде. Спецификация —
`docs/superpowers/specs/2026-10-16-culture-reader-design.md`, план —
`docs/superpowers/plans/2026-10-16-culture-reader.md`.

## Команды

Один раз — окружение с jieba (системный Python Homebrew не даёт ставить пакеты, PEP 668):

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

```bash
.venv/bin/python3 scripts/book.py check            # формат, длина, уровень, источники; код 1 при ошибках
.venv/bin/python3 scripts/book.py build            # только принятые уроки → book/out/中国文化故事.pdf и .epub
.venv/bin/python3 scripts/book.py build --drafts   # все уроки, у непринятых пометка «черновик»
```

PDF печатает Google Chrome без окна. `book/out/` не коммитится.

## Устройство урока

Файл `book/src/<блок>/NN-<id>.md`; блоки и их диапазоны — `book/blocks.json`.

```
---
id: myth-change-benyue
block: myths
title: 嫦娥奔月
image: img/myth-change-benyue.png
status: draft            # draft → checked → accepted
---

Текст абзацами. Слово с ручным пиньинем — {逢蒙|Féng Méng}.

### Подзаголовок части (для длинных уроков)

> 原文：дословная цитата первоисточника (не проверяется на уровень и не входит в длину)

**例句**

1. Пример употребления (чэнъюй).

## 生词
- слово | pīnyīn | перевод на русский

## 判断正误
- утверждение | 对 или 错

## 回答问题
- вопрос | ответ для ключей

## 来源
- kind (official / academic / retelling) | название | ссылка | дословная цитата | ГГГГ-ММ-ДД

## 注
Примечание по-русски.
```

Пиньинь над словом ставится при первом появлении в уроке, если слово выше HSK 4 или это имя:
из пометки `{слово|pinyin}`, из «生词» или из списка HSK 5–6 (`book/hsk/hsk20.tsv`). Слово вне
HSK 1–4 без пиньиня — ошибка проверки. Одиночный иероглиф HSK 5–6 (倒, 根, 派…) пиньинь из списка
не получает — нужна пометка `{倒|dǎo}` или «生词»: чтение зависит от слова. Иероглиф, у которого уже
был пиньинь в другом слове этого урока (射 после 射箭), считается знакомым — кроме многозначных
(`POLYPHONES` в `scripts/book_level.py`: 藏 в 西藏 и в 藏药 читается по-разному). Слово вне HSK,
которое скрипт разбирает на знакомые части, тоже требует пометки, если в нём есть иероглиф с
редким для ученика чтением (`RARE_READINGS`: 当成 — dàng, 背着 — bēi); базовые 地, 着, 得, 了
ученик HSK 4 читает в обоих чтениях, на них правило не действует.

В колодах Anki бывают опечатки в пиньине (从此 записано cōngcǐ). Исправленное чтение —
`book/hsk/fixes.tsv` (слово, верный пиньинь, причина); пиньинь из списков проверяющий сверяет
так же, как ручной.

`book/hsk/extra.tsv` — слова, которые ученик HSK 4 знает, но которых нет в списках отдельным
словом (天, 中, 但 — в списках только 天气, 中国, 但是). Каждая строка с причиной. Спорное
(月饼, 平安) сюда не вносится — ему ставится пиньинь в уроке.

## Порядок работы над блоком

1. Писатель: урок по описанию и образцам, `status: draft`, источники в `## 来源`,
   `book.py check` без ошибок. Для тем со ★ — по возможности упомянуть ответы олимпиадных
   вопросов банка по теме (в тексте или в «注»).
2. Проверяющий — отдельный агент, не писавший урок: опорные факты (имена, даты, числа,
   авторство, ядро сюжета) — по официальному или академическому источнику с цитатой; живые
   подробности — хотя бы в одном изданном пересказе, иначе убрать; язык HSK 4+; весь пиньинь
   над словами, включая взятый из списков (ошибка в списке — строка в `fixes.tsv`); задания и ключи;
   нет близкого пересказа вырезки «Легенты, идиомы, люди.pdf» или чужих сайтов; цитаты XX века —
   не длиннее двух предложений, не больше двух на урок.
3. Правки, `status: checked`, `build --drafts`, PDF — автору.
4. Принятые автором уроки — `status: accepted`.

Агентов запускать только с согласия автора на каждый запуск, не больше трёх одновременно.

## Что ждёт проверяющего в готовых уроках

- 守株待兔: в «注» — замысел Хань Фэя (критика правления по обычаям древних царей,
  «今欲以先王之政，治当世之民，皆守株之类也») — нужна ссылка на текст «五蠹».
- 西游记: первое издание 1592 г. (世德堂本), путь длиной 14 лет, годы похода Сюаньцзана,
  1986 — сериал ЦТВ, 2024 — «黑神话：悟空» — нужны источники.
