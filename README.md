# Тренажёр по лингвострановедению (ВсОШ, китайский язык)

[![Deploy to GitHub Pages](https://github.com/bronik04/lingvostranovedenie-trainer/actions/workflows/pages.yml/badge.svg)](https://github.com/bronik04/lingvostranovedenie-trainer/actions/workflows/pages.yml)

Банк вопросов раздела «Лингвострановедение» Всероссийской олимпиады школьников
за 2015/16 — 2026/27 и тренажёр к нему: вопрос по-русски, варианты по-китайски,
у каждого проверенного ответа пояснение и ссылка на источник.

**Демо:** https://bronik04.github.io/lingvostranovedenie-trainer/
(GitHub Pages, `.github/workflows/pages.yml` — при каждом push в `master`
банк пересобирается из первоисточников, прогоняются оба набора тестов,
и только после этого публикуется новая версия).

Файл самодостаточный: можно просто скачать `dist/lingvostranovedenie-trainer.html`
и открыть его локально без сервера и интернета.

## Сборка

    python3 scripts/import_sources.py     # sources/ -> data/raw/
    python3 scripts/merge_bank.py         # data/raw/ -> data/bank.json + отчёты
    python3 scripts/regions.py            # решения по региональным вариантам: data/review/regions.md и
                                          # страница отложенных заданий data/review/regions-excluded.html
    python3 scripts/taxonomy.py           # проставить темы
    python3 scripts/coverage_map.py       # карта покрытия: data/review/coverage.md
    python3 scripts/pinyin.py             # пиньинь: data/bank.json -> data/pinyin.json
    python3 scripts/build_html.py         # data/bank.json -> dist/ (на сайт — что разрешает data/site.json)

`data/pinyin.json` пишет только `scripts/pinyin.py` (нужен `pip install pypinyin==0.55.0`,
в CI ставится сам); неверное чтение многозначного иероглифа исправляется в
`data/pinyin-phrases.json`, после чего скрипт запускается заново. Без этого шага сборка не
падает: текст без записи просто идёт без транскрипции, а сборка пишет, сколько таких строк.

Снятые автором принятые вопросы перечислены в `data/review/removed.json` (причина и дата):
под их id у учеников остался прогресс, поэтому id не выдаются снова — `scripts/dossiers.py`
и сборка остановятся на вопросе с таким id.

Оформление — дизайн-система «Тушь и киноварь». `src/ink/` — копия её токенов и
компонентов: здесь не править, правка идёт в систему, сюда — новая копия. `src/fonts/` —
Cormorant Garamond и Onest (SIL OFL 1.1, тексты лицензий рядом); сборка встраивает их в
страницу, поэтому она работает без интернета. Стили самого тренажёра — `src/quiz.css`,
только семантические токены системы. Картинка превью ссылок пересобирается вручную:
`python3 scripts/render_og_image.py` (нужен Google Chrome).

## Замечания к вопросам

Включить режим отладки: **Ctrl + Shift + E** (на Mac — **⌘ + Shift + E**),
кнопка «Отладка» в шапке или **«Вид» → «Отладка вопросов»** на телефоне.
Во время раунда нажмите **«Отметить вопрос»**; кнопка **«Комментарий»** позволяет
сразу записать сомнение. Комментарии сохраняются автоматически. Режим работает
в выборе ответа, «Вспомни сам», «Верно или нет» и «Чэнъюй».

В полосе отладки откройте **«Замечания»**: здесь можно дописать комментарий,
снять отметку, **выгрузить файл для Codex** или скопировать отчёт. На поддерживаемых
телефонах доступна кнопка «Поделиться». Прикрепите JSON-файл в чат с Codex и
попросите проверить замечания и исправить вопросы по правилам проекта.

Файл содержит стабильные id, комментарии, снимки вопросов и точные варианты,
показанные при отметке, включая предложенный ответ в «Верно или нет».
Выгрузка не удаляет замечания. Они хранятся отдельно от учебного прогресса,
**только в этом браузере**: телефон и компьютер имеют отдельные списки;
очистка данных браузера удалит их. Сохраняйте выгрузки перед очисткой.

## Тесты

    npm ci                                  # playwright-core для браузерного теста
    python3 -m unittest discover -s test -t . -v
    node --test test/*.test.mjs

`test/ui.test.mjs` открывает собранный `dist/` в установленном Google Chrome без окна
и проходит тренажёр как ученик: раунд, итоги, база, фильтры, телефон. Без Chrome
локально пропускается.

## Данные

`sources/` — неизменяемые первоисточники, их контрольные суммы в `sources/manifest.json`.
Региональные варианты школьного и муниципального этапов (9–11 классы, 35 регионов) в репозиторий
не кладутся — это больше 100 МБ PDF: источник для них — расшифровка `data/regions/variants.json`
(текст задания из бланка, ключ, путь в папке вариантов, контрольная сумма файла), решение по каждому заданию — `data/review/regions.json`. Сверить расшифровку с бланками:
`python3 scripts/regions.py --sources <папка 03-ВСОШ>`.
`data/bank.json` — канонический банк, единственный источник правды для сборки. На сайт идёт то, что разрешает
`data/site.json`: с 2026-10-26 вопросы из региональных вариантов скрыты (кроме встроенных темами «Четыре великих»,
«Государство», «Современный Китай»), план возвращения — `data/review/regions-later.md`.
`data/review/` — отчёты слияния, рубрикации и волн проверки ответов.

К олимпиадным вопросам `merge_bank.py` добавляет дополнения `data/authored/questions.json`, затем
вопросы досье `data/dossiers/` (таблица фактов `<id>.json` и вопросы по её ячейкам
`<id>-questions.json`; в банк идут только принятые автором, проверка без сборки —
`python3 scripts/dossiers.py`). Ручные слои поверх собранного банка лежат в `data/review/` и
накладываются в таком порядке: `editorial.json` (правки текста) → `merges.json` (склейка дублей; с пометкой
`"distractors": "pool"` — один вопрос с общим набором неверных вариантов) → `retired.json`
(удалённые записи пар с разными ответами, прогресс переезжает на оставшуюся) →
`withheld.json` (олимпиадные задания с неразрешённым сомнением: в банк не идут, пока автор его не снимет) →
встраивание олимпиадных вопросов в досье (`embeds`: общий набор из таблицы и подписи из ячеек) →
`fact-groups.json` (метки «один факт», раунд берёт из группы один вопрос) → `glosses.json`
(подписи к неверным вариантам и, у вопросов вне досье, названия верных ответов — в `answer.gloss`).

## Раздел «Чэнъюй»

Задание ЛГ-теста «Подберите аналог фразеологизму в русском языке»: 35 олимпиадных заданий
(`data/chengyu/olympiad.json`) и составленные черновики (`data/chengyu/drafts.json`, в раздел
идут только принятые). Бланки и ответы олимпиады — `sources/chengyu/` со своим манифестом.
Проверка данных — при сборке; сверка с PDF (нужен poppler):

    python3 scripts/chengyu.py --sources

Спецификация: `docs/superpowers/specs/2026-10-15-chengyu-mode-design.md`.
