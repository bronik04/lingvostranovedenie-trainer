## Инструменты (готовы, свои не пиши)
1. **Найти страницу** — WebSearch (лучше с `allowed_domains` из sources.md: people.com.cn, news.cn,

2. **Скачать** — `python3 <S>/fetch.py <S>/cache-<часть> <имя> <url> [<имя> <url> …]`. Сохраняет
   текст страницы в `<S>/cache-<часть>/<имя>.txt` (первая строка — URL), понимает gzip, GB-кодировки,
   PDF, делает три попытки, повторно не качает. Перед скачиванием загляни в `<S>/common/` и чужие
   `<S>/cache-*/`: страница могла уже быть скачана.
3. **Найти цитату** — читай `.txt` (grep, sed). Проверить цитату:
   `python3 <S>/quote.py <файл .txt> "<цитата>"`. Посчитать слова: `python3 <S>/words.py "<цитата>"`.
4. **Собрать черновик** — пиши строки в `<S>/briefs/<часть>-rows.py` (образец помощников `S()` и `C()`
   — ниже): `CACHE = 'cache-<часть>'`, `ROWS = [...]`. У каждого источника, кроме `title`, `url`,
   `quote`, `authority`, — поле `page`: имя страницы в кэше или путь с «/» от `<S>`
   (`cache-ev-cn-2/xinhai-people`). Затем
   `python3 <S>/build.py <S>/briefs/<часть>-rows.py <S>/drafts/<часть>.json` — он сверит каждую
   цитату с копией страницы, снимет `page`, поставит `checkedAt` и выбросит несошедшиеся источники.
5. **Проверить черновик** — `python3 <S>/check_rows.py`. Добейся «ошибок нет» по своим строкам. Ошибки
   ссылок на строки другой, ещё не собранной части допустимы — их сведу я. Список «встраивание —
   пока нет ячеек»: варианты твоей части из него должны исчезнуть.
Сохраняй работу по ходу: сначала `rows.py`, потом build и check.

```python
from pathlib import Path
CACHE = 'cache-<часть>'
_ROOT = Path(__file__).resolve().parent.parent

def S(page, title, quote, authority='official'):
    """Источник: url берётся из первой строки сохранённой страницы."""
    file = _ROOT / (f'{page}.txt' if '/' in page else f'{CACHE}/{page}.txt')
    url = file.read_text('utf-8').split('\n', 1)[0].strip()
    return {'title': title, 'url': url, 'quote': quote, 'authority': authority, 'page': page}

def C(zh, gloss=None, ru=None, ref=None):
    cell = {'zh': zh}
    if ru: cell['ru'] = ru
    if ref: cell['ref'] = ref
    if gloss: cell['gloss'] = gloss
    return cell
```

## Ячейки
- Ячейка-вариант: `{"zh": "…", "ru": [...], "gloss": "…"}`, по желанию `"ref": "…"`. Описательная
  колонка `about` — строка по-русски (2–3 предложения: годы, кто, что, чем кончилось).
- **`zh`** — по-китайски, ДОСЛОВНО как в олимпиадных вариантах из embed-targets.json, иначе — как в
  твоих источниках. Без ячейки вариант не получит подпись, и вопрос не встроится.
- **`country`** — `C('中国')` или `C('俄罗斯')`, без `ru` и без подписи. **`kind`** (только `events`) —
  один из 战争, 起义, 运动, 革命, 改革, 事变, 战役, 会议, 事件; без `ru` и без подписи.
- **`year`** — «1840 年» (четыре цифры, пробел, 年) — год начала события / подписания договора;
  `ru` — `["1840 год"]`; подпись — «1840 год: начало Первой опиумной войны». Одинаковый год в
  разных строках — одна подпись на всех (check_rows это ловит): если в твоей части два события
  одного года, подпись называет оба.
- **`ru`** — русские названия, по которым ответ узнаётся в тексте вопроса: только от шести букв или
  из двух слов («Опиумная война», «Линь Цзэсюй», «Владимир Ленин», «Сталинградская битва»).
  Короткие однословные («Ленин», «Мао») не писать. Транскрипция имён — по Палладию.
- **`gloss`** — подпись под неверным вариантом после ответа: русское название и один факт ЕЁ колонки
  («Линь Цзэсюй — императорский комиссар, в 1839 году уничтожил опиум в Хумэне»; «1898 год: «Сто
  дней реформ»»). Не длиннее 90 знаков, одна строка, без «почему не подходит», без иероглифов ячейки.
  Подпись не должна делать свой вариант вторым верным ответом во встраиваемом вопросе — прочитай их
  формулировки в embed-targets.json (у 袁世凯 не пиши «временный президент» без «второй»; у 朱可夫 —
  можно «маршал Победы», но он и так будет исключён из набора вопроса о полководце ВОВ).

## Объём (решение автора)
Заполняй все колонки своей таблицы, которые подтверждает цитата источника строки; нет цитаты — нет
ячейки. Значения в колонке по возможности разные. Однородность: одна колонка — один вид значения
(в `place` — населённые пункты или точные места, не провинции вперемешку с городами; в `slogan` —
лозунги, в `idea` — учения и принципы; в `post` — должности). Если в колонке вид разный — напиши в
ответе.

## Источники
- У каждой строки не меньше двух независимых источников: разные страницы, лучше разные организации.
  Каждый — `{"title", "url", "quote", "authority": "official"|"academic", "page"}`.
- **Подходят:** см. `<S>/sources.md` — Синьхуа, Жэньминь жибао, cpc.people.com.cn, 12371.cn, gov.cn,
  81.cn, CCTV, МИД КНР, музеи, cssn.cn, jds.cass.cn, hprc.org.cn; для России — kremlin.ru, prlib.ru,
  histrf.ru, historyrussia.org, музеи; китайское написание российского имени — по Синьхуа / Жэньминь
  жибао / МИД КНР.
- **Не подходят:** Википедия, baike.baidu.com, sohu, 知乎, 360doc, блоги, справочные сайты.
- **`quote`** — дословный фрагмент страницы на её языке, подтверждающий ячейки строки. Коротко:
  **не больше 25 слов на одну публикацию** (китайский текст — словами jieba: `words.py`), и куски
  одной страницы в разных строках складываются — поэтому одна страница не должна служить многим
  строкам. Один источник — одна цитата; если факты на странице в разных местах, бери фрагмент, где их
  больше, а остальные ячейки подтверждай другими источниками. Не пересказ. Каждую ячейку строки
  (и каждый факт `about`, и подпись) должна подтверждать хотя бы одна цитата — значит, третий и
  четвёртый источник допустимы.
- **Нет двух источников** — строку не добавляй и назови её в ответе. Особенно если это вариант
  встраиваемого вопроса.
- **Спорные даты и формулировки** (начало войны сопротивления 1931 / 1937, ихэтуани 1899 / 1900,
  авторство лозунга) — ячейку не заводи или заводи по совпадению двух источников, а расхождение
  назови в ответе.
- Чувствительные темы — только факты источников, без оценок.
