## Решения ночи — на утверждение автора

1. **Объём** — 111 строк в 10 частях вместо ~90 в 7–8 (сбор с запасом, решение автора 2026-10-16).
2. **Китайские названия русских промыслов без китайского источника.** У многих промыслов нет китайской
   официальной формы. Такие ячейки — транскрипция места по таблице Синьхуа + общее слово; факты строки
   подтверждены российскими источниками. Список (name / center):
   - crafts: 姆斯乔拉微型漆画 / 姆斯乔拉 (Мстёра; у АОН Китая — 姆斯乔尔), 霍卢伊微型漆画 / 霍卢伊 (Холуй),
     费多斯基诺微型漆画 / 费多斯基诺 (Федоскино; center — форма олимпиады), 戈罗杰茨彩画 / 戈罗杰茨 (Городец),
     波尔霍夫迈丹彩画 / 波尔霍夫迈丹 (Полхов-Майдан), 斯科平陶器 / 斯科平 (Скопин), 巴甫洛夫斯基波萨德披肩 /
     巴甫洛夫斯基波萨德 (Павловский Посад), 克拉斯诺耶花丝工艺 / 克拉斯诺耶 (Красное-на-Волге), 库巴奇银器 /
     库巴奇 (Кубачи), 卡斯利铸铁艺术品 / 卡斯利 (Касли); только name — 奥伦堡羊绒披肩, 托尔若克金线刺绣,
     大乌斯秋格乌银; только center — 大罗斯托夫 (Ростов Великий: 罗斯托夫 в «Провинциях» — Ростов-на-Дону),
     古斯赫鲁斯塔利内 (форма «Этносов»), 耶列茨 (по 耶列茨蕾丝 Минкоммерции).
   - folk: 德姆科沃玩具 / 德姆科沃 (Дымково), 菲利莫诺沃玩具 / 菲利莫诺沃, 卡尔戈波尔玩具 / 卡尔戈波尔,
     阿巴舍沃玩具 / 阿巴舍沃, 谢苗诺夫套娃 / 谢苗诺夫, 卢博克版画 (лубок; в академических текстах —
     «俄罗斯民间版画»), 彼得鲁什卡木偶戏 (имя — по АОН, «木偶戏» добавлено).
   Вопросы «как называют по-китайски» писатели ставят только о строках с китайским источником названия.
   Если автор против транскрипций — строки остаются для набора, а вопросы с ними в ответе снимаются.
3. **Хохлома** — `name` 霍赫洛玛装饰画 (Минкоммерции, как в «Этносах», `ref`), `center` 霍赫洛马 (форма
   олимпиады addition-b2-19; так же пишут посольство РФ и АОН Китая). Других форм — 霍霍洛玛 (Чжунго синьвэнь),
   霍赫洛姆 (列国志) — в таблице нет. Правка варианта addition-b2-19 в `editorial.json` не нужна.
4. **Встраивание addition-b2-19** (Палех) по колонке `center` с `exclude` Холуя и Мстёры: оба — иконописные
   сёла с лаковой миниатюрой (Холуй ещё и в Ивановской области), без исключения у ученика два ответа.
5. **Эпоха — только однозначная.** Где источники пишут «始于唐，盛于宋» или расходятся, ячейки `era` нет
   (сведения — в `about`): у пяти печей Сун (钧, 汝, 定, 龙泉…), 德化, 建盏, 磁州窑, 缂丝, 北京雕漆, 斑铜,

   战国 у 扬州漆器 и 春秋 у 龙泉宝剑 (периоды; у меча — по преданию), 隋 у 浚县泥咕咕 — по преданию.

8. **Сняты сессией вопреки «на решение автора»:** q130 (Петрушка — отсев не устранить) и в q74 вариант
