# Материалы для чтения после ответа — 2026-11-07

Решение автора: показывать после любого ответа; предпочитать русскую Википедию,
при отсутствии статьи использовать другие материалы; охватить все вопросы,
по которым есть что почитать.

## Реализация

Внизу разбора находится блок «Почитать подробнее», видимый после ответа во всех
трёх форматах основного тренажёра. Ссылки открываются в новой вкладке. В разделе
«Чэнъюй» тем же блоком показываются уже имеющиеся словарные источники (81 задание).

Каталог `data/reading.json` содержит 607 статей по строкам досье и 113 назначений
для отдельных вопросов. Сборка выбирает явное назначение вопроса, затем материал
строки досье, затем подходящий источник из банка. У источников предпочтение имеет
русская Википедия, затем русские сайты, затем остальные. Повторяющиеся ссылки
исключаются; показывается не больше двух статей. При отсутствии материала нет
пустого заголовка. Главные страницы сайтов, PDF, DOC/DOCX и небезопасные адреса
не используются.

Охват опубликованного банка: **998 из 998** вопросов; у **914** есть статья
русской Википедии, у остальных **84** — материалы из существующих источников.
Счёт отражает `data/site.json` на дату проверки. Каталог не добавляет сведения
к пояснениям и не меняет формулировки, ответы, id или доказательные источники.
Новые вопросы могут использовать подходящий источник до отдельного подбора статьи.
Интернет требуется только при переходе по ссылке.

## Проверка подбора

Для статей Википедии использован MediaWiki API: точное название, нормализация,
перенаправления, языковые ссылки из китайских статей. Несуществующие страницы и
помеченные страницы неоднозначностей исключены. Результаты сопоставлены с именами
строк досье и формулировками вопросов. Автоматическое совпадение названия само
по себе не доказывает правильность темы: независимое ревью дополнительно нашло
и устранило омонимы.

Исправлены, в частности: фильм «Броненосец „Потёмкин“» вместо корабля; пьеса
«Чайка» вместо птицы; роман «Мать»; чай Лунцзин вместо города; картина «Девятый
вал» вместо природного явления; река Амур вместо провинции Хэйлунцзян; телескоп
FAST; чай Кимун; пустыня Гоби в вопросе `2026-27-mun-2`. Для сычуаньской вышивки,
чудовища Нянь и Каменного леса Шилинь ошибочные совпадения удалены, сохранены
подходящие существующие источники. Источники, на которые ссылался банк, не
переписывались и не заменялись энциклопедией.

Тесты проверяют выбор и наследование материала, отсутствие изменений банка,
пустые и небезопасные ссылки, известные омонимы, охват опубликованных вопросов,
скрытие до ответа, показ после верного и неверного ответа во всех форматах,
экранирование подписей и словарные материалы «Чэнъюй».

Итоговый прогон: сборка успешна; 492 Python-теста и 172 Node-теста прошли без
ошибок и пропусков. Разбор просмотрен в Chrome при 1280×900 и 375×812: ширина
страницы не переполнена, высота области ссылки 44 px, ссылка доступна над нижней
панелью следующего вопроса. Защищённые файлы банка и рабочих слоёв не менялись.
